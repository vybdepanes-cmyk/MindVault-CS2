# MindVault-CS2
a digital vault for all your tasks, notes, and school thoughts ♡
## About the Project
MindVault is a student organizer designed to help keep school tasks, deadlines, and notes in one place. It aims to make managing responsibilities easier and less overwhelming.
## Planned Features
- Task Tracker
- Digital Notes Storage
- Workload Overview
- Search Function
